# Agent Instructions

This is a Gleam web application using Lustre for the UI and lustre_stylish for CSS-in-Gleam styling.

## Tech Stack

- **Language**: Gleam (targeting JavaScript)
- **UI Framework**: Lustre
- **Styling**: lustre_stylish

## Commands

```sh
gleam run -m lustre/dev start  # Start dev server with hot reload
gleam test                     # Run tests
gleam build                    # Build for production
```

## Project Structure

- `src/alley_mah_jong.gleam` - Main application entry point
- `test/` - Test files
- `gleam.toml` - Project configuration
